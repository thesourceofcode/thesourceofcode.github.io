### BRANCH AUTOMATION

**Sep 1975 – Oct 1995 · Associated with Central Bank of India**

> As per Rangarajan committee, branch automation in 2 wings was started. One was called ALPM - Advance Ledger Posting Machines and the other Total Branch Automation (TBA). While ALPM was inhouse, TBA was outsourced. The tricky point was in ALPM there were many restrictions agreed with trade unions. Memory cannot exceed 256 K, no hard disks to be used but only 5 1/4 floppies. It was a real challenge. Without any additional hands, I designed, developed, tested and implemented in 3 main branches of the Bank. Later, created a team, trained them well with full documentation and implemented all over India.
>
> For TBA, I was given the task of automating the biggest branch in Nariman Point. The task was to select a vendor, technology, testing, getting masterdata created and implement in a unionied environment. It was really a task and manged very well

### MIS for Bank

**Jul 1980 – Dec 1982 · Associated with Central Bank of India**

> This was my first project to be done independently. Every Friday the bank has to submit data to Reserve Bank of India, details of all the branches on about 35 parameters. Branches will send the forms to Central office where the data has to be punched on cards and processed. This was done on ICL 1903. It was a tough job for a junior person to develop and implement. In Banks there was no compartmentalisation. You have to do all. This gave me strong technical skills, good system development capability. I had done much more than an MIS system by linking the data to all possible ways to other types of information like branch categorisation, HR related MIS etc. My first independent project earned me good name
